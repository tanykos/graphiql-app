# REST/GraphiQL Client  

## Project's Description 
A light-weight versions of Postman and GrqphiQL combined in one app.  
The project was developed by a team of 3 members according to the  task [link](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/final.md).

[Deploy link](https://graphiql-qidfaux3k-tanykos-projects.vercel.app/en)  
  
[Demo video](https://youtu.be/iLjk49haH7E)  

*Useful information:*
- Use {{ }} for variables, e.g. {{url}}?search=luke , where "url" equals to "https://swapi.dev/api/people/".
- Don't forget to add "Content-type: application/json" to the headers, if you want to receive JSON data in response.

## Application structure

+ Welcome page
+ User registration/authentication
+ RESTfull client
+ GraphiQL client
+ History page
